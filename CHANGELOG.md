# Changelog

## 0.1.0 - 2026-11-12

- Initial release.
- Three display modes for the hidden-thinking line: `hide`, `digest` (default), `latest`.
- `/td-mode` command and `Ctrl+Shift+K` hotkey to cycle modes; persisted across sessions.
- Wall-clock thinking duration measurement with one-line summaries.
- Per-turn folding in `latest` mode: one line per user turn, not per assistant message.
